Learning Pathway

Neural_Kit tutorials

Step-by-step, beginner-friendly tutorials teaching neural networks from the ground up using native Ada 2022. No previous deep learning experience needed.

Recommended Path: If you are new to Neural_Kit, start with the Beginner Tutorial Guide. It is an interactive 7-lesson course with runnable code, mental models, breakdown of concepts, common gotchas, and exercises.

Course curriculum

  1. Scalars & Vectors in Ada

    Master Ada's unconstrained array semantics, 1-based indexing, stack memory efficiency, and the Scalar and Vector types.

  2. Linear algebra from first principles

    Dot products, matrix-vector multiplication, outer products, Hadamard operations, and positional slicing without dimension mismatches.

  3. Activation functions & numerical stability

    Understand non-linearities: Sigmoid with exponential clipping, ReLU, Tanh, and Softmax with maximum-value subtraction.

  4. Loss functions: Quantifying prediction error

    Compare Mean Squared Error (MSE) and Binary Cross-Entropy (BCE) with safe ε-clamping against log-zero errors.

  5. PRNG & reproducible weight initialization

    Why random weights matter: explore PCG32 pseudo-random numbers, Box-Muller Gaussian sampling, and Xavier (Glorot) / He (Kaiming) initializers.

  6. Building & training a single neuron

    Construct a single neuron, feedforward inputs, compute cross-entropy error, and train the neuron to learn the logical AND operation using gradient descent.

  7. Multi-neuron dense layers

    Scale from a single neuron to multi-neuron layers: configure weight matrices, bias vectors, activations, forward inference, and backpropagation gradient flow.
