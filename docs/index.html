Your first Neural_Kit program

Here is a complete, standalone Ada 2022 program that creates a single neuron, feeds a two-dimensional input, activates it with the sigmoid function, and computes binary cross-entropy loss against a target:

with Ada.Text_IO;       use Ada.Text_IO;
with Neural_Kit.Neuron; use Neural_Kit.Neuron;
with Neural_Kit.Types;  use Neural_Kit.Types;

procedure Main is
   --  Create a neuron with 2 input features and initial weights
   N : Neuron := New_Neuron (Weights => (0.5, -0.2), Bias => 0.1);

   Input_Sample : constant Vector (1 .. 2) := (1.0, 0.5);
   Target_Label : constant Scalar := 1.0;

   Prediction : Scalar;
   Error_Loss : Scalar;
begin
   --  Forward pass and non-linear activation
   N.Forward (Input_Sample);
   N.Activate;

   Prediction := N.Output;
   Error_Loss := N.Loss (Target_Label);

   Put_Line ("Prediction: " & Scalar'Image (Prediction));
   Put_Line ("Loss:       " & Scalar'Image (Error_Loss));
   Put_Line ("Classified: " & Boolean'Image (N.Classify_Binary (Input_Sample)));
end Main;

Save this as src/main.adb and run it with alr run.

Architecture pillars

PillarDesign Philosophy & ImplementationAdvantage for Machine Learning
Strong Typing & ContractsAda 2022 preconditions (Pre => ...) enforce that vector lengths and matrix inner dimensions match before any computation starts.Eliminates dimension mismatch crashes and silent broadcasting errors before they can corrupt weights.
Deterministic MemoryZero garbage collection. Tensors and vectors use Ada unconstrained array objects allocated on the stack or in predictable records.Deterministic execution with zero GC pauses, delivering predictable throughput and immediate memory reclamation.
Numerically HardenedActivations feature exponential clipping and Softmax uses maximum-value subtraction; BCE loss uses ε-clamping (10⁻⁷).Guarantees that intermediate values never overflow to ±∞ or NaN on extreme inputs.
Reproducible PRNGIndependent generator instances using PCG32 (Permuted Congruential Generator) with Box-Muller normal transforms.Bitwise-reproducible model initialization across Linux, macOS, and Windows without hidden global state.
