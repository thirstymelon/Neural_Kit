Architecture & Ada 2022 Implementation

The digit classifier is implemented as a standalone project in examples/mnist_classifier/ using exclusively the features available in Neural_Kit v0.2.0. The model trains with 8-direction shift augmentation, achieving 100% test accuracy (20/20) on held-out samples and 100% shift invariance.

Ada 2022 Inference Code

-- Feed 64 downsampled pixels into hidden layer
Hidden_Layer.Forward (Pixels);
Hidden_Layer.Activate;  -- ReLU

-- Compute 10-class Softmax distribution
Output_Layer.Forward (Hidden_Layer.Output);
Output_Layer.Activate;  -- Softmax

Prediction := Output_Layer.Output;
Predicted_Digit := Argmax (Prediction);
