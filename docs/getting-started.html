Setup & Installation Guide

Getting started with Neural_Kit

Learn how to set up the Ada 2022 toolchain with Alire, build Neural_Kit, run the automated test suite, and wire the library into your own projects.

Prerequisites: The Ada toolchain

Neural_Kit is written in modern Ada 2022 and is packaged for the Alire package manager. To get started, you only need Alire installed on your system.

1. Installing Alire

Alire (Ada Literate REpository) automatically manages your GNAT compiler, GPRbuild, and project dependencies on Linux, macOS, and Windows.

  • macOS (Homebrew): brew install alire
  • Linux / Windows: Download the official release binary from alire.ada.dev or install via your distribution's package manager.

Verify your Alire installation:

alr --version     # e.g., alr 2.0.2

Building Neural_Kit

Clone the repository and build the library using Alire:

# Clone the repository
git clone https://github.com/thirstymelon/Neural_Kit.git
cd Neural_Kit

# Build the core library
alr build

Alire will automatically download and configure the GNAT toolchain (if not already present), compile the Ada packages, and generate the static library lib/libNeural_Kit.a.

Running the included examples

Neural_Kit includes two standalone projects in examples/ demonstrating real-world classification benchmarks:

1. Iris Flower Species Classification

Trains a multi-neuron network on Fisher's classic Iris plant dataset (4 features, 3 species) using He-initialized ReLU hidden layers and Softmax outputs:

cd examples/iris_classification
alr run

2. Handwritten Digit Recognition (MNIST)

Trains an 8x8 bitmap handwritten digit classifier (64 inputs, 10 digit classes 0..9) with visual ASCII art rendering and confidence distribution bar charts:

cd examples/mnist_classifier
alr run

Running the automated test suite

Neural_Kit includes a comprehensive automated test runner verifying linear algebra, numerical stability, activations, loss calculations, Box-Muller PRNG distributions, and gradient checking:

# Build and execute the test runner
gprbuild -P tests/tests.gpr
./tests/bin/test_runner

Repository structure

The library is structured into modular units:

PathPackageDescription
src/neural_kit-types.adsNeural_Kit.TypesDefines Scalar (Float32), unconstrained Vector and Matrix, and framework exceptions.
src/math/Neural_Kit.MathPure linear algebra (Dot, Multiply, Hadamard), activations (Sigmoid, ReLU, Tanh, Softmax), and losses (BCE, MSE).
src/random/Neural_Kit.RandomIndependent PCG32 generator, Box-Muller normal transforms, and Xavier / He initializers.
src/neuron/Neural_Kit.NeuronTrainable single neuron with arbitrary dimension inputs and gradient descent updates.
src/layer/Neural_Kit.LayerDense multi-neuron layer with weight matrix, bias vector, activations, and backpropagation gradient flow.

Using Neural_Kit in your own project

To use Neural_Kit in your own Ada application:

  1. Create a new Alire project: 
    alr init --bin my_neural_app
cd my_neural_app
  2. In your project's GPR file (my_neural_app.gpr), add the reference to Neural_Kit: 
    with "../Neural_Kit/neural_kit.gpr";

project My_Neural_App is
   for Source_Dirs use ("src");
   for Object_Dir use "obj";
   for Main use ("main.adb");
end My_Neural_App;
  3. Write your code in src/main.adb and run alr run.
