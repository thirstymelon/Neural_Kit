Architecture & Internals

Developer overview

A deep dive into the engineering principles, memory models, contract-based verification, and numerical stability design of Neural_Kit.

The Ada advantage in deep learning

Modern machine learning frameworks (like PyTorch and TensorFlow) are typically built on a hybrid architecture: high-level Python glue wrapping complex C++ backends. While flexible for research, this architecture introduces major operational challenges in production pipelines and robust systems:

  • Garbage Collection Overhead: Python runtimes introduce non-deterministic garbage collection cycles and memory fragmentation that degrade throughput during intensive training loops and high-concurrency inference services.
  • Memory Safety Vulnerabilities: C++ tensor memory management is prone to out-of-bounds pointer corruptions, buffer overflows, and use-after-free defects that can compromise server reliability.
  • Silent Shape Mismatches: In dynamically-typed frameworks, implicit array broadcasting often conceals bugs where tensors of incompatible dimensions silently combine into unintended shapes without warning.

Neural_Kit is designed to provide an alternative: a pure, strongly-typed machine learning framework built natively in Ada 2022. It offers deterministic stack allocation, formal dimension verification via preconditions, and high numerical stability.

Memory model: Zero-GC unconstrained arrays

In Neural_Kit, linear algebra structures are represented as unconstrained Ada arrays:

type Vector is array (Positive range <>) of Scalar;
type Matrix is array (Positive range <>, Positive range <>) of Scalar;

Why unconstrained arrays instead of heap pointers?

  1. Stack Allocation: Local vectors and intermediate matrix operations are allocated on the secondary stack or runtime stack. When a function finishes execution, its memory is reclaimed instantly without a garbage collector.
  2. Positional Slicing: Ada arrays can have arbitrary valid bounds (e.g., V (5 .. 8)). Neural_Kit's mathematical subprograms match elements positionally from first to last, rather than assuming that every array starts at index 1.
  3. Pass-by-Reference: Large vectors and matrices are passed efficiently by reference under the hood by the GNAT compiler, avoiding expensive memory copies.

Matrix dimension conventions

Neural_Kit strictly follows the standard mathematical and neural network conventions:

  • Rows represent Output Neurons.
  • Columns represent Input Features.

Therefore, when computing layer feed-forward inference:

y = W · x + b

where W has dimensions (Rows × Cols), x has length Cols, b has length Rows, and the resulting vector y has length equal to Rows.

Design by Contract & Exception Semantics

Neural_Kit relies on Ada 2022 contracts (with Pre => ..., Post => ...) to guarantee mathematical compatibility before executing any loop.

--  Example of strict contract specification in Neural_Kit.Math
function Multiply (M : Matrix; V : Vector) return Vector
  with Pre  => M'Length (2) = V'Length,
       Post => Multiply'Result'Length = M'Length (1)
       and then Multiply'Result'First = 1;

Numerical stability engineering

Training neural networks frequently encounters boundary values that can derail computation if not guarded:

1. Softmax Maximum-Value Subtraction

Evaluating ez directly can easily exceed 32-bit float limits (e89 ≈ 1038). Neural_Kit computes Softmax using shift invariance:

Softmax(zi) = ezi - max(z) / ∑ ezj - max(z)

Since the maximum exponent is now e0 = 1.0, floating-point overflow is mathematically impossible.

2. Sigmoid Clamping

For inputs |z| > 45.0, e-z underflows or overflows. Neural_Kit returns exact saturated limits: 0.0 for z < -45.0 and 1.0 for z > 45.0.

3. Loss Epsilon Protection

Binary cross-entropy involves ln(p) and ln(1 - p). If a prediction reaches 0.0 or 1.0, ln(0) evaluates to -∞. Neural_Kit automatically clamps inputs to [ε, 1.0 - ε] where ε = 10⁻⁷.

PRNG & Statistical Reproducibility

Neural_Kit uses PCG32 (Permuted Congruential Generator XSH-RR 64/32) for pseudo-random number generation:

  • State: 64-bit state and 64-bit increment, producing a period of 264.
  • Independence: The generator is encapsulated inside type Generator is limited private;. There is zero hidden global state, allowing multiple independent threads or simulations to run side by side without interference.
  • Box-Muller Normal Sampling: Transforms uniform random variables into Gaussian distributions using spare-value caching to avoid redundant logarithmic and trigonometric calls.
