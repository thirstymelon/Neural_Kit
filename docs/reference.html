Package Neural_Kit.Types

The foundation package declaring scalar, vector, and matrix data types, along with package-level exceptions and backward compatibility aliases.

Types & Subtypes

Matrixtype Matrix is array (Positive range <>, Positive range <>) of Scalar;Unconstrained 2D array indexed by Positive. Row-major indexing: M(Row, Column).

Exceptions

ExceptionRaised When
Dimension_ErrorArray lengths or matrix dimensions mismatch for an operation that requires geometric compatibility (e.g. dot products of different length vectors, incompatible matrix-vector multiplications).
Numerical_ErrorAn invalid mathematical domain is encountered, such as non-positive standard deviation in PRNG initialization or undefined probability inputs outside [0.0, 1.0].

Package Neural_Kit.Math

All core linear algebra, activation functions, derivatives, and loss functions are consolidated within Neural_Kit.Math.

Constants

Epsilon : constant Scalar := 1.0e-7; — Threshold used for numerical stability in logarithms and probability clamping.

Package Neural_Kit.Neuron

Implements the foundational single-neuron binary classifier unit with sigmoid activation and gradient descent training.

Record Type

type Neuron (Input_Dimension : Positive) is tagged record
   Weights        : Vector (1 .. Input_Dimension);
   Bias           : Scalar := 0.0;
   Pre_Activation : Scalar := 0.0;
   Output         : Scalar := 0.0;
end record;

Subprograms

SubprogramSignatureDescription
New_Neuronfunction New_Neuron (Weights : Vector; Bias : Scalar) return Neuron;Constructs a new neuron with normalized 1-based weights and specified bias.
Forwardprocedure Forward (Self : in out Neuron; Input : Vector);Requires Input'Length = Self.Input_Dimension. Computes pre-activation net sum z = w · x + b.
Activateprocedure Activate (Self : in out Neuron);Applies logistic sigmoid activation a = σ(z).
Lossfunction Loss (Self : Neuron; Target : Scalar) return Scalar;Requires target in [0.0, 1.0]. Returns binary cross-entropy loss against current output.
Updateprocedure Update (Self : in out Neuron; Input : Vector; Target : Scalar; Learning_Rate : Scalar);Performs one step of analytical gradient descent: ∇z = a - y, wi ← wi - η · ∇z · xi, b ← b - η · ∇z.
Predictfunction Predict (Self : in out Neuron; Input : Vector) return Scalar;Forward propagates, activates, and returns a = σ(w · x + b).
Classify_Binaryfunction Classify_Binary (Self : in out Neuron; Input : Vector) return Boolean;Discretizes continuous prediction probability into True or False against threshold 0.5.

Package Neural_Kit.Layer

Implements multi-neuron dense (fully connected) layers with configurable activation functions, initialization schemes, forward propagation, and analytical backpropagation.

Enumerations

type Activation_Kind is (Linear, Sigmoid, ReLU, Tanh, Softmax);

type Initialization_Kind is (Zeros, Uniform, Xavier, He);

Record Type

type Layer (Input_Dimension : Positive; Output_Dimension : Positive) is
  tagged record
   Weights          : Matrix (1 .. Output_Dimension, 1 .. Input_Dimension);
   Biases           : Vector (1 .. Output_Dimension);
   Pre_Activation   : Vector (1 .. Output_Dimension) := (others => 0.0);
   Output           : Vector (1 .. Output_Dimension) := (others => 0.0);
   Activation       : Activation_Kind               := Sigmoid;
   Weight_Gradients : Matrix (1 .. Output_Dimension, 1 .. Input_Dimension) :=
                        (others => (others => 0.0));
   Bias_Gradients   : Vector (1 .. Output_Dimension) := (others => 0.0);
end record;
